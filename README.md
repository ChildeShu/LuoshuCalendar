# 洛书日历 (Luoshu Calendar)

Windows 任务栏时钟增强工具：在系统托盘时钟位置绘制一个自定义日历面板，支持农历、节气、法定节假日、日程角标，并通过右键菜单进行交互。单文件 WinForms 应用，使用 C# 手写控件（不依赖 Visual Studio 窗体设计器）。

## 功能特性

- 任务栏时钟区域嵌入日历面板（覆盖在系统时钟之上，`WS_EX_NOACTIVATE` 无焦点窗口）
- 右键菜单：切换显示 / 关闭，点击任务栏或其他任意位置自动消失
- 农历、节气、法定节假日显示
- 日程/待办角标
- 悬停提示（右键菜单弹出时自动抑制，避免互相干扰）

## 运行要求

- Windows 10 / 11
- .NET Framework 4.8（Windows 通常已自带；若未安装请从微软官网下载）

## 下载与使用

本仓库中的 `LuoshuCalendar.exe` 即为程序本体，单文件、免安装，下载后直接双击运行即可。运行后点击任务栏通知区域（系统托盘）的洛书日历图标，通过右键菜单进行各项设置。

> 本仓库为公开分发版，仅提供可执行文件。
